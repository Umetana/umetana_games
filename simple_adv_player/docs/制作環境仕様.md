# Simple ADV Player 制作環境仕様

## 1. 環境の分離

公開プレイヤーと制作環境は実行条件を分離する。

- 公開プレイヤーはVanilla HTML/CSS/JavaScriptのみで構成し、HTTP/HTTPSによる静的配信で動作する。
- 公開物はNode.js、データベース、ビルドツール、外部APIを実行時に必要としない。
- 制作環境はNode.jsを使用できる。作品ファイルの直接読み書き、バックアップ、素材管理、プレビュー配信、公開物生成を担当する。
- エディターUIはブラウザで表示するが、制作サーバーのローカルAPIを通してファイルを操作する。

## 2. 制作サーバー

- `127.0.0.1`だけで待ち受け、LANや外部ネットワークへ公開しない。
- 操作対象はプロジェクト内の`works/`と`dist/`に限定する。
- APIから任意の絶対パスを受け取らない。
- 作品IDは英数字、ハイフン、アンダースコアだけを許可する。
- リクエストサイズに上限を設ける。
- `game.json`保存前に以前のファイルを作品内`.backups/`へ退避する。

## 3. API

```text
GET  /api/status
GET  /api/works
GET  /api/works/{id}/game
PUT  /api/works/{id}/game
GET  /api/works/{id}/assets
POST /api/works/{id}/assets
POST /api/works/{id}/package
```

## 4. エディター

- 起動時に作品一覧を取得し、選択作品の`game.json`を直接読み込む。
- 保存時は共通Validatorを通し、成功したデータだけを制作サーバーへ送る。
- LocalStorageは未保存下書きの復旧補助として残すが、正式な保存先にはしない。
- JSONファイルの読み込みとダウンロードは、移行・バックアップ用の補助機能として残す。
- 素材プレビューは選択作品のフォルダを基準に解決する。

## 5. 公開物

- 制作サーバーまたはパッケージスクリプトが`dist/{作品ID}/`を生成する。
- 公開物は作品単体で完結し、開発用APIやエディターを含めない。
- 公開先には`dist/{作品ID}/`の内容だけを配置する。
