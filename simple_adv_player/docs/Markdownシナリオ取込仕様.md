# Markdownシナリオ取込仕様

## 目的

長い台本をシーン単位で一括して`game.json`の`scenes`へ変換し、細かな命令はエディターで調整します。取り込みは即時保存せず、エディター上の未保存編集として反映します。

## 記法

```markdown
# opening

@background castle_road
@character left yu_normal

ユウ：
おしろは
もうすぐかな？

地の文だけの段落もメッセージになります。

@hide left
@jump next_scene

# next_scene

@end つづく
```

- `# scene_id`: シーン開始。IDは半角英字で始め、半角英数字と`_`を使用します。
- `話者名：`に続く段落: 話者付きメッセージ。半角の`:`も使用できます。
- 話者名を付けない段落: 話者なしメッセージ。
- `@background 素材ID`: 背景を表示。
- `@character left|center|right 素材ID`: 立ち絵または敵を表示。
- `@hide left|center|right`: 指定位置の立ち絵を消去。
- `@jump シーンID`: シーン移動。
- `@end 終了文`: 終了。終了文を省略した場合は「おしまい」。

空行でメッセージ段落を区切ります。未対応タグ、未登録素材、存在しない移動先、重複シーンはプレビュー時にエラーになります。

## 反映方法

- 全シーンを置換: `scenes`全体を変換結果に置き換えます。
- 同名シーンを置換・新規を追加: 取り込んだシーンだけを置き換えます。
- 同名シーン末尾へ追記・新規を追加: 既存命令の末尾へ追加します。既存末尾が`end`の場合は、その直前へ追加します。
- 新規シーンだけ追加: 同名シーンを変更しません。

反映後は通常の検証と「作品へ保存」を実行します。保存時には従来どおりバックアップが作成されます。

## 新規作品

作品IDは半角英字で始め、半角英数字・`_`・`-`を使用します。フォルダ名、`game.game.id`、LocalStorageのセーブ識別に使うため、公開後は変更しません。新規作品は素材なし・タイトル画面なしの`formatVersion: 1`で作成され、素材とタイトル画面はエディターで追加します。
