# タイトル画面仕様

## 概要

`formatVersion: 2`の作品は起動時にシナリオを実行せず、プレイヤー共通のタイトル画面を表示します。旧形式の`formatVersion: 1`は従来どおり自動開始・自動再開します。

## game.json

`game`へ次の設定を追加します。

```json
{
  "formatVersion": 2,
  "game": {
    "titleScreen": {
      "background": "title",
      "newGameLabel": "はじめから",
      "continueLabel": "つづきから"
    }
  }
}
```

- `background`: `assets.backgrounds`に登録した素材ID
- `newGameLabel`: 新規開始ボタンの文言
- `continueLabel`: 再開ボタンの文言

## 動作

- 「はじめから」はセーブを削除して`game.startScene`から開始します。有効なセーブがある場合は確認を表示します。
- 「つづきから」は作品IDとリビジョンが一致する有効なセーブがある場合だけ選択できます。
- 設定画面の「タイトルへ もどる」は現在の自動セーブを保持してタイトルへ戻ります。
- タイトル画面から音設定を変更できます。
- タイトル画面はシナリオのシーンではないため、シーン移動や選択肢命令は不要です。

エディターでは「タイトル画面」タブから背景と文言を編集できます。旧形式の作品には同タブに有効化ボタンが表示されます。
