# 将来機能メモ

現時点では実装対象にせず、仕様検討時の案として記録する。命令名、データ形式、細かな挙動は未確定。

## ウェイトと画面切替演出

- 指定時間だけ進行を止めるウェイト命令
- 暗転・暗転解除を行うフェードアウト／フェードイン命令
- 次の背景変更やシーン移動へフェードなどを指定するトランジション
- 暗転中に背景や立ち絵を複数変更してから復帰できる構成
- プレイヤー、Validator、エディター、Markdown取込を同時に対応させる

記法案：

```markdown
@wait 500
@fadeout 500
@background castle_night
@hide left
@character center last_boss
@fadein 700
```

## 章によるシーン整理

- 章は当初、ゲーム進行用フラグではなくエディター整理用メタデータとして扱う
- 既存のシーンIDと`jump`の仕組みは変更しない
- エディターでは章単位の折りたたみ、並べ替え、未分類グループ、シーン検索を検討する
- Markdown取込では章IDと表示名を明示する記法を検討する
- 将来、章選択やクリア状況が必要になった段階で進行データとの連携を検討する

記法案：

```markdown
@chapter forest 第1章 はじまりの森

# forest_intro
# forest_battle
```
