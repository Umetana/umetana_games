# キショコメ・マージ v0.1.0

PCブラウザ向けの落ち物合体パズルです。シリーズの入口ページからは、このフォルダーのURLへリンクします。

タイトルで「通常」「しなるカード」「ゲル」を選べます。しなるカードは衝撃や荷重で曲がり、
ゲルは押された方向につぶれ、横へ広がります。ハイスコアはモード別です。
変形の強度や戻り方は `config.mjs` の `materials` で調整できます。

## ローカルで遊ぶ

リポジトリのルートで `python -m http.server 8080` を実行し、ブラウザで
`http://localhost:8080/kishocome-merge/` を開きます。既存の静的ファイルサーバーでも動作します。

公開時はこのフォルダーをそのまま GitHub Pages の配信対象に含めます。パスはすべて相対指定です。

## 技術構成

Canvasで盤面を描き、スコアやメニューにはHTMLを使います。回転する長方形の衝突と積み上げに
Matter.js 0.20.0を採用しました。ライブラリを同梱する分だけ配信サイズは増えますが、CDN接続や
ビルド工程が不要で、120Hzの固定ステップで合体と危険ラインの時間を管理できます。
SEはWeb Audioで生成します。

カード寸法、物理、解禁時間、得点は `config.mjs`、カード文面とBAN専用文面は
`comments.json` で調整できます。危険ラインは床につながる接触が120ms続いたカードを対象にし、
次のカードは最初の接地から160ms後、接地がなければ投入から最大1350msで操作可能になります。

盤面にカードがあるとき、Fキーかシェイクボタンで1プレイに1回だけ山を揺らせます。
危険ラインのカウントは通常どおり進みます。揺れの強さは `config.mjs` の `shake` で調整できます。
